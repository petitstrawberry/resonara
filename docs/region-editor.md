# 下部エディタ

アレンジメントの下部は **Mixer / Editor** を切り替える共通ペインです。
Logicの[選択した音声リージョンを拡大して編集する構成](https://support.apple.com/en-au/guide/logicpro/lgcp21587d1c/mac)を参考にしています。
現在はオーディオに対応します。MIDIピアノロール、ドラムパターン、Melodyneのような音符検出・音符単位のピッチ補正は今後の機能です。以前の全体移調の欄は通常の音声編集画面から外しました。

## 開く・選ぶ

- **X**：Mixerを開閉。**E**：Editorを開閉。同じペインのタブでも切り替え可能。
- アレンジメントでリージョンをダブルクリックすると、そのリージョンのEditorを開きます。
- 選択リージョンが変わると波形とパラメーターが追従します。Auxまたは未選択では案内を表示します。
- 上下の仕切りをドラッグして高さを変更。ペインの×で閉じます。

## 波形・範囲・再生位置

モノは1段、ステレオはL/Rの2段。波形をドラッグして範囲を選択します。選択端をドラッグするとその端を調整し、Shift＋クリックで範囲を延長できます。ダブルクリックまたはCmd/Ctrl+Aで全選択。Escapeでドラッグを取り消します。

左側のStart / Endに秒またはサンプル数を入力し、Enterで範囲を確定できます。Zero crossingをOnにすると、マウスの選択端を近くの音源のゼロクロスへ合わせます。数値入力・キー操作にはこの補助を適用しません。

**エディタ上部のルーラーでもクリック・ドラッグで再生ヘッドを移動できます。** 表示範囲とリージョンの開始位置を考慮し、再生中は離した位置へシークして再生を継続します。Escapeで取り消し。音声範囲の選択は維持し、アレンジメントの音楽グリッドへは吸着させません。波形の単クリックも再生位置を移動しますが、範囲ドラッグは移動しません。

Editorのズーム・横移動はアレンジメントと独立しています。

- 虫眼鏡または **+/−**：拡大・縮小。Fitアイコンまたは **F**：全体表示。Selectionの虫眼鏡：範囲を拡大。
- ホイール：横移動。下部のスクロールバーまたは左右ボタンでも移動できます。
- Cmd/Ctrl＋ホイール：ポインターを中心にズーム。Option/Alt＋ホイール：波形の表示倍率。
- サンプル単位まで拡大すると、実サンプルを結んだ線と点を表示します。
- 左右キー：選択カーソル移動。Shift＋左右で範囲延長。Option/Alt＋左右は1サンプル。Home / Endはリージョンの端。
- 波形にフォーカスがある時のSpace：選択開始位置から再生・停止。

## 範囲の編集

コピー・貼り付け・削除・分割などは波形上のツールバーから実行できます。CutとTrimは右クリックの編集メニューまたはショートカットで使います。ハサミのアイコンはSplitです。以下のショートカットは波形にフォーカスがある時に使います。

| 操作 | 動作 | キー |
| --- | --- | --- |
| Copy | 選択した音源をアプリ内クリップボードへコピー | Cmd/Ctrl+C |
| Cut | コピーして選択部分だけを削除。時間は空けたまま | Cmd/Ctrl+X |
| Paste | 再生ヘッドの位置へ独立したリージョンとして貼り付け | Cmd/Ctrl+V |
| Delete | コピーせず選択部分だけを削除。時間は空けたまま | Delete / Backspace |
| Silence | 長さを保って選択部分を無音化 | — |
| Reverse | 範囲があればその音声を反転、なければリージョン全体を反転 | — |
| Trim | 選択部分だけを残す | Cmd/Ctrl+T |
| Split | 範囲の両端で分割して中央を選択、カーソルのみならその位置で分割 | S |

Delete / Cutは選択部分の両端で分割し、その部分だけを取り除きます。残る音声や他のリージョンの時刻は変わりません。時間を詰めるCut Time / Delete Timeは実装していません。全選択して削除するとリージョン自体を取り除きます。選択範囲のないDeleteは何も削除しません。

コピーは元音源を共有するリージョンの区間として保持し、反転・ゲイン・フェードの包絡も維持します。貼り付けは[LogicのAudio Track Editor](https://support.apple.com/en-ae/guide/logicpro/lgcp88368f2a/10.7/mac/11.0)と同様、選択トラックの再生ヘッド位置へ新しいリージョンとして置きます。後続の音声を押し出したり、前へ詰めたりしません。クリップボードはアプリ内だけで、異なるプロジェクトサンプルレートへの貼り付けには現在対応しません。

## レベル・フェード

- **Gain**：トラックinsertより前のリージョンゲイン。−60〜+24 dB。
- **Fade in / out**：ミリ秒入力、または波形上端の金色ハンドルをドラッグ。Escape / pointer cancelで元に戻し、離した時に1回のUndoとして確定。
- **Normalize**：リージョン全体のピークを指定したdBFSへ合わせ、リージョンゲインへ反映。
- **Waveform倍率**：表示だけの拡大。音量を変えません。

元音源は変更しません。トリム・分割後は同じ音源を共有し、途中で切ったフェードの包絡を維持します。フェードを改めて操作すると新しい端へ設定します。Cut / Delete後の左右の区間も包絡を継承します。

変更は通常のUndo / Redo、保存・再読込、WAV書出しへ反映されます。音声処理と新しい波形ピークの集計はワーカーで実行し、Cancel processingで取り消せます。再生を継続でき、DSPやCLAPインスタンスは保持します。競合するプロジェクト編集があれば結果を破棄します。処理用音声バッファの上限は512 MiBです。

## 実装

- `lower_panel.rs`：共通ペインとタブ。素材別Editorの追加箇所。
- `region_editor.rs`：範囲、独立した表示範囲、保持波形、ルーラーとフェードの操作。
- `region_editor_menu.rs` / `region_audio_edits.rs`：範囲メニュー・クリップボード操作。
- `region_processing.rs`：ワーカー処理、キャンセル、結果照合とUndoへの接続。
- core `region_edit.rs` / `audio_edit.rs`：ソース範囲・包絡とサンプル編集。

再生ヘッド・選択範囲だけの描画では波形メッシュを再生成しません。非表示のEditorでは波形を生成しません。
