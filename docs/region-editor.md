# 下部エディタ

アレンジメントの下部は **Mixer / Editor** を切り替える共通ペインです。
Logicの[選択した音声リージョンを拡大して編集する構成](https://support.apple.com/en-au/guide/logicpro/lgcp21587d1c/mac)を参考にしています。
Editorは素材別の編集画面を置く場所として分離してあり、現在はオーディオに対応します。MIDIピアノロール、ドラムパターン、検出した音符のピッチ編集はまだありません。

## 開く・選ぶ

- **X**：Mixerを開閉。**E**：Editorを開閉。同じペインのタブでも切り替え可能。
- アレンジメントでリージョンをダブルクリックすると、そのリージョンのEditorを開きます。
- 選択リージョンが変わると波形とパラメーターが追従します。Auxまたは未選択では案内を表示します。
- 上下の仕切りをドラッグして高さを変更。ペインの×で閉じます。
- Auxの削除はインスペクターの名前横にある小さな「⋯」メニューへ移動しました。

## 波形と範囲

モノは1段、ステレオはL/Rの2段。波形をドラッグして範囲を選択し、Escapeで選択ドラッグを取り消せます。
Editorのズーム／横移動はアレンジメントと独立しています。Fitでリージョン全体、Selectionで選択範囲を拡大。
サンプル単位まで拡大でき、左右キーで選択カーソルを移動、Shift＋左右キーで範囲を延ばせます。

- **Trim**：選択範囲だけを残します。
- **Split**：範囲があれば両端で分割し中央を選択、カーソルだけならその位置で分割します。
- **Gain**：トラックinsertより前のリージョンゲイン。−60〜+24 dB。
- **Fade in / out**：ミリ秒で長さを指定するリニアフェード。
- **Reverse**：リージョンを反転します。
- **Normalize**：指定したdBFSへピークを合わせ、リージョンゲインへ反映します。

元のサンプル配列は変更しません。分割・トリム後も同じ音源を共有し、元のフェードの途中で切った場合はその包絡を維持します。
この場合は「Fades follow original edges」を表示し、Reset fadesで継承したフェードを取り除いてから新しい端のフェードを設定できます。
変更は通常のUndo／Redo、プロジェクト保存・再読込、WAV書出しに反映されます。

## ピッチ

**Pitch · st** に半音単位で−12.00〜+12.00を入力し、Transposeを実行します。0.01半音は1セントです。
リージョン全体の音程を変え、開始位置とフレーム数を保ちます。音符検出や部分ごとの補正、フォルマント保持は行いません。
位相を揃えたphase vocoderと帯域制限リサンプリングを使うため、大きな移調ではアタックや声質が変わることがあります。

処理はワーカースレッドで実行し、Cancel processingで取り消せます。処理中も再生と画面操作を継続できます。
処理結果は新しい音源として選択リージョンだけに反映し、他のリージョンとUndo用の元音源は保ちます。
競合するプロジェクト編集が行われた場合は結果を破棄して、別のリージョンへ誤適用しません。
一度の処理用音声バッファは512 MiBを上限とします。長い素材は短いリージョンへ分割して処理してください。

## 実装

- `lower_panel.rs`：共通ペインとタブ。素材別Editorの追加箇所。
- `region_editor.rs`：選択、独立した表示範囲、保持波形、編集操作。
- `region_processing.rs`：非同期処理、キャンセル、結果の世代照合とUndoへの接続。
- core `region_edit.rs`：ソース範囲、フェード、ゲイン、反転、トリム／分割。
- core `pitch.rs`：固定長・ステレオのオフライン移調。外部DSPライブラリーやOS固有APIは使わずRustFFTを使用。

再生ヘッドと選択範囲の描画は波形メッシュの再生成を要求せず、非表示のEditorでは波形を生成しません。
